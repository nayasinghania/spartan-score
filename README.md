# Spartan Score

## About

Spartan Score is a GPA calculator designed for SJSU students to be able to easily calculate their GPA with just a screenshot of their grades. May or may not work with screenshots of Canvas grades from other universities.

### Tech Stack

- Next.js
- Shadcn UI
- Tesseract OCR

## Setup

1. `bun install`
2. `bun dev`
3. `http://localhost:3000`
